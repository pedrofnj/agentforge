# AgentForge v0.2.0

> **Real-World Tested** — AgentForge has been used in a real-world project for security auditing
> and code quality analysis.

## Highlights

- **Interactive install wizard.** `agentforge install` on a terminal detects your system,
  Node.js, Claude Code and Codex (without running them) and previous installs, then asks for the
  client, the scope (showing the exact directories), the agents and optional skills, previews
  every change and installs atomically with a progress bar and a final summary.
- **Interactive uninstall** that removes skills no remaining agent needs and keeps shared ones.
- **`agentforge status`**: versions, file integrity and available updates, also as `--json`.
- **Install scripts** for a repository checkout: `scripts/install.sh` (Linux, macOS) and
  `scripts/install.ps1` (Windows), with no `sudo`, no execution-policy changes and no remote
  scripts.
- `--provider` and `--scope` aliases, `--json` for `list` and `doctor`, more `doctor` checks.
- Still zero runtime dependencies: the arrow-key prompts are built on `node:readline`.

## Install or upgrade

```bash
npx @pedrofnj/agentforge@latest install
npm install --global @pedrofnj/agentforge@0.2.0
agentforge status
agentforge update --global --yes    # and/or --project
```

Existing installs keep working: the state format is unchanged and all 0.1.x flags
(`--client`, `--global`, `--project`) are still accepted.

## Compatibility

- Node.js: 22, 24 · OS: Linux, macOS, Windows (CI, including the install scripts)
- Claude Code / Codex formats verified on: 2026-11-15 (unchanged from 0.1.x)

## Known limitations

- No measured effectiveness metrics yet: the offline benchmarks have not been scored against
  client sessions.
- The generated Codex files have not yet been loaded in a live Codex session.
- Codex cannot make a single agent read-only; the session sandbox decides.
