# AgentForge v0.1.1

Maintenance release: the first one published by the release workflow through npm trusted
publishing (OIDC, with provenance). No functional changes to the CLI, agents or skills.

## Install or upgrade

```bash
npx @pedrofnj/agentforge@latest install
npm install --global @pedrofnj/agentforge@0.1.1
```

## Changes

- Release workflow installs npm 11 before publishing (required for trusted publishing).
- `docs/releasing.md` documents the publishing setup and the staged-publishing decision.
