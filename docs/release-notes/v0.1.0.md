# AgentForge v0.1.0 (draft, not released)

First public release candidate of AgentForge: read-only AI reviewers and skills for Claude Code
and OpenAI Codex, for any language or framework.

## Highlights

- Five specialist agents: AppSec, architecture, code quality, performance, infrastructure.
- Six stack-agnostic skills with progressive loading (short description always, instructions on
  use, references on demand).
- A safe installer: plan first, no overwrites without consent, rollback of interrupted
  operations, removal only of files it can prove it installed.
- Quick / standard / deep profiles and economy / balanced / thorough budgets.
- An offline evaluation framework with 43 benchmark cases and ground truth.

## Verified for this release

- [x] CI configuration for Linux, macOS, Windows on Node.js 22 and 24 (runs once pushed)
- [x] Package validation locally on Windows / Node 24 (pack, install, CLI round trip)
- [ ] Live check in Claude Code
- [ ] Live check in Codex
- [ ] Evaluation runs with real agents (effectiveness not measured yet)

## Known limitations

- Package `@pedrofnj/agentforge` (command `agentforge`); benchmarks are not in the npm package.
- Agent effectiveness has not been measured with real client sessions.
- Codex cannot make a single agent read-only; use a read-only session sandbox for audits.
