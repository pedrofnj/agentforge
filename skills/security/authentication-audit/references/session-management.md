# Session management

- Identifier: generated by a cryptographically secure random source, long enough to resist
  guessing, never derived from user data or time.
- Rotation: new identifier after login and after privilege changes (prevents fixation).
- Expiry: idle and absolute timeouts enforced on the server.
- Invalidation: logout and password change destroy server-side session state.
- Cookies: `Secure`, `HttpOnly` and an appropriate `SameSite`; scoped path and domain.
- Storage: session data on the server; client-side state is signed or encrypted and validated.
- CSRF: state-changing requests are protected when sessions use cookies.
